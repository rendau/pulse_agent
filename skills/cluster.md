name: cluster
title: Кластер целиком
when: «лежит всё / много сервисов», «что с кластером», ошибки в логах без названного сервиса
---
get_cluster_health первым: ноды (готовность, давление), поды в проблемных состояниях по всему
кластеру, Warning-события по причинам, инфраструктурные алерты (не привязанные к сервисам), загрузка
CPU и памяти против вчера, log_errors — ошибки в логах по сервисам. Дальше — снапшоты одного-трёх
самых пострадавших сервисов, не всех подряд. Для ответа: общее или частное (одна нода, один
namespace, один сервис тянет остальных).
